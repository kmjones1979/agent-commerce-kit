# docs/demo.mp4

The deliverable asks for `docs/demo.mp4` — a ~30-second screen recording of the
pizza-order approval flow. That is a **manual screen capture** (it cannot be
generated by the kit), so it is not committed here.

To record it, follow **[../DEMO.md](../DEMO.md)** section "Approval path" and
capture your screen (e.g. macOS `Cmd-Shift-5`, or `quicktime`), then save the
clip as `docs/demo.mp4`. Keep it to the pizza flow: prompt → Ampersend approval →
order placed → transaction appears in the status strip and /audit.
